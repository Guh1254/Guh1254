## 🏆 Projeto Destaque: Projeto Paz (Kotlin Multiplatform & IoT)

> *Uma solução completa de gestão com arquitetura unificada para Android, iOS, Web e Desktop, integrada com pipeline de telemetria de dados via IoT.*

* 📄 **Artigo Técnico Publicado:** Aprovado e apresentado no **8º EnGeTec (Encontro de Gestão e Tecnologia)**.

| Componente | Tecnologias Utilizadas |
| :--- | :--- |
| **Frontend (KMP)** | Kotlin Multiplatform, Compose Multiplatform, Ktor Client |
| **Backend** | Spring Boot 3, Kotlin, Spring Security (JWT), Spring Data JPA |
| **Infra & Dados** | MySQL, AWS S3 (Armazenamento de Imagens), Docker |
| **IoT & Telemetria** | Integração de hardware (ESP32 + Sensores) para ingestão e análise de dados |
