## 🏆 Projeto Destaque: Projeto Paz (Kotlin Multiplatform)

> *Uma solução completa de gestão para vendedores informais, desenvolvida com arquitetura unificada para Android, iOS, Web e Desktop.*

| Componente | Tecnologias Utilizadas |
| :--- | :--- |
| **Frontend (KMP)** | Kotlin Multiplatform, Compose Multiplatform, Ktor Client |
| **Backend** | Spring Boot 3, Kotlin, Spring Security (JWT), Spring Data JPA |
| **Infra & Dados** | MySQL, AWS S3 (Armazenamento de Imagens), Docker |
| **IoT** | Integração de hardware (ESP32 + Sensores) para coleta e análise de dados |
